# 现有玩法

## 常用操作

| 场景 | 输入 | 行为 |
| --- | --- | --- |
| 步行 | W/S/A/D、Space、Shift | 移动、跳跃、冲刺 |
| 步行 | C、E、R | 攀爬、交互、登船 |
| 步行 | 鼠标左键 / 右键 | 攻击 / 瞄准或星际能力 |
| 步行 | F | 切换选中的腰灯 |
| 装备 | 1–9、方向上/下 | 选择快捷栏位置、翻页；空位也可选择 |
| 装备 | Q | 短按丢弃、长按销毁；堆叠物品打开数量选择 |
| 武器 | Tab、Z、T、X | 切换星际装备；Z 普通枪换弹或切换星际模式；T 普通枪换弹；X 返回普通武器 |
| 视角 | V、滚轮 | 切换视角、缩放 |
| UI | J、Alt、I、Esc | 图鉴、按住临时鼠标模式、切换鼠标模式、关闭当前界面 |

交互提示与当前装备决定动作是否可用。飞船输入单列于 [飞船系统](Spacecraft.md)。

## 背包与成长

物品由 Item Definition 和具体实例共同描述，实例可带规格、等级等信息。拖动交换、丢弃、转入船柜和放置到扫描区均由服务器校验，不能只交换 UI 图标。飞船共享资源、个人船柜、星际装配与普通背包是不同存储空间。

普通物品堆叠上限为 99。角色成长目前包含背包格数、跑速、体力、暴击率、生命和防御；旧的堆叠上限升级已停用，序列化枚举保留兼容。不能继续把它列为可购买成长。

可升级物品最高等级 101，最高品阶 5，暴击倍率 1.75。具体购买价格与成长曲线由实现和配置决定。Wearable 装备流程已经移除，旧枚举保留不代表仍存在完整穿戴玩法。

## 普通武器与采集

当前可升级普通武器包括短刃、冲击杆、动力锤、轨道手枪、突击步枪、霰弹枪、轨道狙击枪、重机枪、榴弹发射器和电弧枪。旧测试用 Pistol 等隐藏条目不作为当前可购武器清单。

采矿镐使用资源自身的采集工作量，反馈与产出由服务器确定。资源产出、区域混合和生态关系见 [月球玩法](Moon.md)。

## 星际装配

当前有五类核心与十二类附件。装配界面有九个位置：四对配对位加一个备用位；远征人数为 1 / 2 / 3 / 4 时，每人开放 4 / 3 / 2 / 1 对。只有兼容核心与附件正确配对时才形成对应能力。

星际物品可进入普通背包；兼容实例会优先堆叠到已有位置，再使用空位。星际物品使用专门堆叠规则，不沿用普通物品的 99 上限。升级堆叠实例前会先分离目标实例，仍需要可用位置，不能同时修改整堆物品。

星际能力共用能量池：基础上限 100，停止消耗 1 秒后以每秒 16 恢复；持续引导期间不按普通空闲恢复。具体能力消耗、冷却与状态效果由核心和附件配置决定。

调试授予入口遵循当前存储 API，不保证所有物品都放入 30 格船柜。联机修改仍走服务器路径。

## 发现、交互与战利品

发现系统以 `ItemId + SpecimenId` 区分类型，尺寸等实例差异不额外制造一个发现类型。团队分析结果由 GameState 上的 DiscoveryComponent 复制；J 打开图鉴查看名称、标签和来源。未分析物体的显示与部分交互能力受识别状态控制。

把实物拖进飞船扫描区域后，由服务器检查真实停泊条件、样本占用和收纳空间。识别成功与收纳成功分别处理，货舱满时不会吞掉世界物体。详见 [扫描与仓储](Spacecraft.md#扫描与仓储)。

月球主坑七个洞口、Boss 与火星权限卡属于具体遭遇配置。外围洞口不因外观相似就获得可摧毁权限，详见 [月球玩法](Moon.md#七巢穴遭遇)。
