# 当前玩法与操作

本文记录已实现的行为；具体资产入口见 [Development.md](Development.md)，月球生成配置见 [Moon.md](Moon.md)。表中的数值为当前配置基准，项目内容仍由 Blueprint / Data Asset 调整。

## 远征、角色与物品

入口支持创建 / 选择房主存档、创建远征、查找 / 加入会话、设置和准备大厅。服务器检查人数、版本与加入凭据；准备完成后由房主推进玩法。当前默认网络服务为 NULL / LAN，EOS 有独立配置示例，公网及语音能力取决于实际 Provider 配置。

Earth 先收集补给，再结算登船与燃料条件并进入 SpaceWorld。原生默认收集 60 秒、发射需要 5 燃料、要求所有连接成员登船；实际参数在 Earth GameMode Blueprint。SpaceWorld 首次到达按 ArrivalAnchor 初始化飞船、玩家和当前 Planet 的地表玩法；角色死亡后的重生要求关联飞船已经着陆。

普通库存以物品实例保存数量、耐久和唯一 ID，定义优先读取 `DA_Item_*`，可选资产不存在时使用原生后备定义。服务器处理拾取、丢弃、交换、消耗与购买。生命、体力、攀爬、搬运、近战和远程分别由现有组件负责；普通枪械包括命中扫描、弹夹 / 换弹、能量枪及投射物配置。

角色经验与加点包含背包容量、堆叠上限、跑速、体力和暴击，随玩家快照保存。飞船终端提供普通商店、星际奖池、个人商店仓库和材料提交；每名玩家的商店仓库有 30 格。石头、金属、水晶可提交到共享飞船库存；一具可拾取蚂蚁尸体提交后转换为一份有机质。

## 飞船飞行与起落

W/S 前进 / 后退，A/D 侧移，Space 上升或起飞，Ctrl 下降，Shift 加速。自由飞行保留六轴意图、飞行辅助与限速；服务器验证驾驶员权限。

近地使用真实地形外的平滑安全包络。组件采样周围地形、完整机身占地及沿实际速度的预测走廊，最高地形向周围形成平滑山肩，再加船体净空和地面间距。贴地状态沿包络切面运动，姿态保持同一切面目标，鼠标方向投影为偏航；持续 Space 上升到释放高度后回到自由姿态。

Ctrl 在包络上方首先是普通下降。服务器预测下降会越过包络下沿时才检查四脚支撑；落点无效或速度过高就限制下降并提示原因。合法落点固定后，立即展开支架，同时下降、调姿和有限平移，不再使用固定准备高度。

四足垫分别检查中心、四边及四角，验证完整接地面、坡度、局部起伏、法线变化、独立行程、重心支撑多边形和机身净空。原落点不合格时最多搜索 51 个附近候选，修正不超过 2 米 / ±8°。LandingSite 保留兼容类型，运行时着陆由真实地形支撑决定。

着陆过程锁住飞行轴及加速，保留相机观察和 Space 中断；每 0.2 秒复检支撑。支架展开前保留最后 20 cm 接地余量，四脚真实接地才进入 Landed。中断后必须松开 Ctrl 才能再次触发着陆。坑内起飞先垂直抬升到周围地形的安全净空，短按 Space 也会完成该阶段；达到后恢复水平飞行。

当前驾驶员在飞行或着陆状态均可按 L 开关前灯。着陆与下船保留灯光状态；地面角色的灯光请求被服务器拒绝。已重叠船体可以沿合法脱离方向缓慢恢复，运动仍检查其他障碍及穿入深度。

## 星际装备与升级

五种核心为火、水、光、暗、药剂，激活颜色分别为橙红、蓝、金、紫、绿。1 / 2 / 3 / 4 名远征玩家分别开放 4 / 3 / 2 / 1 组圆形与下方灰色菱形，另有一个橙色备用槽。只有圆形核心与正下方兼容配件激活武器；备用、错配、跨列及封闭位置不参与。

槽位可自由拖放 / 交换，只接收核心或配件。星际物品从个人商店仓库拖入专用栏，普通背包拒绝接收；旧存档保留迁移路径。封闭列的装备保留，人数减少后可重新开放。所有组合共用玩家星际能量，切换不重置能量或技能冷却。

点击可用槽中的核心可以永久升级，不要求激活组合；服务器扣固件并增加核心点数。配件只有正确配对激活后才能分配六项点数，预算由对应核心提供，保留草案 / 应用 / 调整；移位或组合失效会关闭窗口。服务器验证实例、版本、可用位置、材料和预算。

星际商店现有 `DEBUG 全套物品` 按钮按奖池尝试发放 5 核心 + 12 配件到当前玩家的空仓库格，不发固件，不扣资源、不覆盖已有物品，也不直接装备；空位不足时保留已发放部分。请求仍走终端距离及服务器权限检查。

治疗不复活，多来源合计每秒不超过最大生命 20%，紧急治疗共享 20 秒冷却。同类盾取较强值，光 / 暗 / 水盾合计不超过最大生命 60%；暗盾每次最多返还 5 能量。精英单次硬控制最多 1 秒并共享 4 秒抗性窗口，Boss 不冻结或定身。

碎裂、传染、穿透、连锁和范围查询有次数 / 数量上限；残留火场最多两个、机器人最多九个。失效装备清理持续对象，有效换装后的机器人最多续存 8 秒。工程分解只接受显式 `JTSDisassemblyTarget`，资源沿用原掉落事务；任务物、玩家、飞船及未接入接口的对象不接受工程分解。

燃烧 / 光灼烧显示头部火焰，冰冻显示身体边缘冰晶，腐蚀显示身体局部绿色污块。状态可共存、独立到期；表现覆盖实际 Static / Skeletal Mesh，死亡时清理。冰雹从上空约 9 m 沿星球重力落下，右键不显示核心发射光束。表现由本地 Actor / 实例网格负责，Dedicated Server 不创建美术 Actor。

## 黑洞与斥力细则

服务器根据已验证的相机方向找真实地面落点，并检查角色视点到落点的距离 / 遮挡。天空、超距、墙面 / 天花板、能量不足或冷却中拒绝释放，不扣能量、不替换已有场。

场释放后松手、停止瞄准或换武器仍持续，角色死亡 / 销毁清理。每个核心与配件实例组合独立计数，数量为 `1 + floor(有效点数 / 2)`、最多六个，满额合法释放替换最早场；既有场保留释放时的数值快照。

黑球为无碰撞视觉体，半径 65 cm、底部离地 45 cm；吸力落点仍在真实地面，玩家可以穿过。右键斥力半径 6.5 m，显示透明紫色半球；怪物允许浅入 30 cm 后被强阻尼弹簧推出，静止偏移为边界外 12 cm。

多个吸力 / 斥力来源同时累计，由 Mass 地表移动积分处理，释放一个来源不清除其他来源。速度与加速度有上限，地形扫掠和身体分离继续生效，不把怪物直接传送到边界，也不为每只怪物启用独立 Chaos 刚体。
