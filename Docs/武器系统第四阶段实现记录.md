# 武器系统第四阶段实现记录

日期：2026-10-04。依据《太空合作生存武器系统设计方案》实施第四阶段的代表机制：喷射、聚焦、黑洞。其余九种星际形态与第五阶段尚未完成。

## 界面与物品规则

按用户确认的布局，飞船终端不增加“星际组装”页面。九个星际物品格在“当前玩家物品格”的普通存储上方显示为一行；离开终端后同一份数据在普通快捷栏上方显示。进入终端时隐藏 HUD 的重复星际行。

格子采用普通物品的拖放方式，只接收星际商店奖池中的物品，包括核心、配件、升级固件。普通武器和资源不能放入。核心在左、匹配配件紧邻右侧时自动识别武器；不限定固定奇偶位置。原先组合物品进入星际行时拆成两个保留独立实例 ID 的物品。

容器始终保存九格，任务人数决定可用区域 9／7／5／3。封格物品保留，禁止插入、替换、装备、升级、消耗和加点，允许取出至普通存储或前方空可用格。移动后取消当前星际攻击，重新选择才会使用。

点击配件打开六项技能弹窗，点击与拖拽分开识别。编辑草案、重置、应用均在弹窗内进行，关闭未应用草案保留原记录。记录点数与小数有效等级分开显示，提交校验物品实例、所在格、编辑版本、封格和当前核心预算；旧提交不会覆盖新装备。升级固件可在星际行保存，并由核心弹窗消耗，剩余固件单位保留。

## 系统职责与首轮数值

- `JTSStellarLoadoutComponent`：PlayerState 所有的物品、人数封格、服务器事务、技能记录和公共能量。依赖现有个人存储、角色背包、星际奖池和 Expedition 保存机制。
- `JTSStellarWeaponComponent`：角色上的输入意图、服务器攻击通道、能量支付、代表武器命中规则；资产选择由 Blueprint 配置的目录提供。
- `JTSStellarTargetComponent`：敌人可组合的元素状态、传播、抗性与控制。普通／精英／Boss 类型由 Blueprint 配置；控制方向投影到真实星球切平面。
- `JTSStellarEffectActor`：由 Blueprint 选择网格、材质和表现，原型包含喷流、光束、黑洞与排斥区域。没有在 C++ 硬编码项目资源路径。

| 武器 | 零点基础伤害 | 基础参数 |
| --- | --- | --- |
| 喷射 | 300 伤害／秒 | 6 米；火焰状态伤害 40／秒；基础能耗 22／秒 |
| 聚焦 | 56／发，8 发／秒 | 30 米；零点穿透 1 个额外目标，后续衰减；每发完整支付 2.75 能量 |
| 黑洞 | 150 伤害／秒 | 放置距离上限 20 米；吸引范围 4 米；右键排斥独立支付能量 |

所有形态仅当前所选武器响应输入。Z 循环选择已识别、已配置的星际武器，X 返回普通武器；普通数字选枪也退出星际武器。切换取消当前通道、普通连射与近战，不重置公共能量。

普通敌人可受燃尽处决，精英受有限额外伤害，Boss 转为姿态压力；光灼伤与火焰燃烧分开。传播次数、持续伤害来源和单次范围候选数均有上限。千目标测试最多选择最近 96 个唯一候选。
