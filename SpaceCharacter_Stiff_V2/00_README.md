# 僵硬喜剧人物动作 V2

本版根据用户新增的图 5 交替拳、图 6 外撇折腿跑重新设计，取代上一版偏自然、松散的动作方向。日期：2026-09-29。

**修改范围：地面走/跑的下半身，空手待机/走/跑/拳击的上半身。跳跃、起跳、空中、下落、落地全部保留用户现有设计。持物上半身保留，仅检查与新腿部动作的兼容。**

## 给 Grok 使用

将整个目录放入工程，例如 `D:\projects\space\Docs\SpaceCharacter_Stiff_V2`。复制 `01_GROK_PROMPT_V2.md` 全文给能访问工程、连接 Unreal MCP 的 Grok。也可直接发送：

```text
读取 Docs/SpaceCharacter_Stiff_V2/01_GROK_PROMPT_V2.md 及其引用文件，按 V2 实施。以技术图、姿态参数和我的图 5、图 6 为准，不再执行旧版自然松肩方案。仅改地面走跑下半身、空手上半身及僵硬交替拳，跳跃整套保持原样，持物上半身保持现有设计。先查实际骨骼和运行时接线，再完成动画资产、接入与多人验证，交付文件清单和实际画面证据，不停在建议或伪代码。
```

## 看图顺序

1. `previews/`：先看三个 GIF 的整体节奏。蓝色为角色自己的左肢，橙色为右肢。
2. `Pose_Atlas_V2.pdf`：4 页标准技术图，按走路、跑步、空手上身、拳击排列。每页对应 `designs/` 内同名 PNG/SVG。
3. `02_POSE_SPEC_CN.md`：中文动作定义、关键姿态、数值含义与实现边界。
4. `data/`：同一套参考骨架生成的关键姿态指标及 85 个相位样本。不是 UE 骨骼旋转文件。
5. `references/`：用户本次六张原图，另有上一轮腿脚骨树供检查父子关系。

## 图例与精度说明

| 图中文字 | 中文含义 |
|---|---|
| FRONT / RIGHT SIDE / TOP | 正视 / 角色右侧视 / 俯视 |
| L / R | 角色解剖学左 / 右；正视时角色左侧在画面右边 |
| FORWARD +X | 角色前方；俯视图的页面上方 |
| contact / passing / folded | 接地交接 / 摆动腿经过 / 折腿抬起 |
| phase 0 / 25 / 50 / 75% | 一个完整左右循环的四个关键相位 |
| support foot | 支撑脚；脚下实线表示当前支撑侧 |
| flex_deg | 关节屈曲角；0° 表示完全伸直 |

技术图和 GIF 使用同一套固定肢体长度的三维坐标计算，左右及各投影视图相互对应。它们是 **180 cm 参考人形的动作规范**，不是对用户真实骨长、本地轴、蒙皮或碰撞的测量；Grok 需在实际骨架上求解。图中的圆形手标记表示手末端，不要求走路时一直攥紧拳头。

GIF 是原地动作节奏预览，不是角色已经在真实地面上移动的效果。实际运行必须匹配移速与步幅、锁定支撑脚，不能照搬预览周期。拳击 GIF 的播放速度也不授权改变既有攻击频率。

外观效果图仅供理解便装角色的僵硬轮廓，不是技术关键帧；如透视、左右或关节角度有出入，以技术图和文字为准。
